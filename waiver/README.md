# Consentimientos de María Hesed

María abre su enlace privado para entrar directamente al panel desde su teléfono, computadora o tablet. Puede agregar la app a la pantalla de inicio desde el panel abierto. El icono abre el panel y la sesión se renueva por 30 días al consultarlo. Si una instalación antigua abre la pantalla de bienvenida, puede vincularla pegando su enlace privado en «Panel de María». Cerrar sesión o entrar al modo presencial bloquea ese dispositivo. Para volver a abrirlo, María usa el mismo enlace privado. Desde el panel puede enviar una invitación por correo, copiar un enlace de una sola firma y descargar o eliminar un documento archivado.

Para usar la tablet sin conexión, abre el panel en la app o el navegador que se usará para las firmas y pulsa **Preparar 10 formularios**. Después abre **Modo presencial**. Cada formulario puede generar su PDF sin internet. Tras firmar, descarga la copia y pulsa **Terminar** antes de entregar la tablet a otra persona. Vuelve a abrir la página con conexión para sincronizar las firmas pendientes. Conserva los datos del navegador hasta que el panel indique que se sincronizaron.

El dominio principal es `waiver.mariahesed.com`. Si una red no puede abrirlo, el mismo enlace privado funciona en `mariahesed-waiver.odd-forest-9504.workers.dev` conservando la ruta completa. Las dos direcciones usan el mismo archivo del estudio. Cada origen mantiene su propia sesión y sus formularios pendientes sin conexión.

## Operación

Instala las dependencias desde este directorio con `npm ci`. Ejecuta `npm test` para compilar y probar el Worker con una base D1 local y un transporte de correo simulado. Aplica las migraciones necesarias con `npx wrangler d1 migrations apply mariahesed-waivers --remote` y publica con `npm run deploy`.

El enlace privado tiene la forma `/acceso/<secreto aleatorio de 32 bytes>`. María puede copiar la dirección del panel abierto, guardarla y volver a usarla en otro dispositivo. Los enlaces anteriores con `#entrada` se convierten al nuevo formato al entrar. La vista previa del enlace solo recibe la página de carga. Al pasar a modo presencial o cerrar sesión se retira la dirección privada de la pestaña. D1 guarda su huella SHA-256 en `studio_entrance`. Para revocarlo, elimina su fila de esa tabla. Esto también revoca las sesiones que creó. Para emitir otro, genera un secreto nuevo y guarda solo su huella en la fila `slot=1`. El archivo exclusivo de María se conserva fuera del repositorio. El panel requiere una cookie segura HttpOnly y un identificador privado del navegador para consultar el archivo. El binding privado STUDIO sigue validando los accesos de integraciones existentes. D1 guarda cada PDF y las respuestas cifrados con AES-GCM. Configura RECORD_KEY con una clave de 32 bytes en base64, MAIL_KEY con una clave de envío de Resend y STUDIO_EMAIL con el buzón confirmado del estudio. Conserva la clave de cifrado para poder recuperar el archivo. Su sustitución requiere migrar los registros cifrados existentes.

La firma, el archivo y ambas tareas de correo se confirman en una misma transacción. Los reintentos usan una clave de idempotencia por documento y destinatario. El panel indica cuántas copias ha aceptado el proveedor. Los formularios se conservan hasta que el estudio los elimina del archivo. En la tablet, cada registro cifrado pendiente se elimina después de que el servidor confirme su recepción.

El texto de la versión MH-2026-11-10.1 se transcribió de las dos páginas facilitadas por el estudio. La fuente lo identifica como borrador para revisión jurídica. Conserva cada versión publicada para poder sincronizar documentos ya firmados sin conexión.
